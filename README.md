# GS QVM Mark 

GS QVM Mark is an extension product of the GreenSnake QVM quantum simulation computing software. It is an open-source and free software. 

Currently, it only supports **NVIDIA GPUs**. Users with NVIDIA GPUs who are interested are welcome to download and try it.

## 📊 Benchmark Submission & Community

We are building a database of GPU performance on quantum simulations. To keep everything transparent and organized, we use GitHub Discussions:

*   **🏆 Submit Your Score:** If you want to contribute to this project, please post your **GPU model** and **GS QVM Mark scores** in the **Score Chat** discussion page.
*   **💡 Share Ideas:** If you have new ideas or suggestions, feel free to share them in the **Idea** page.
*   **❓ Get Help:** If you have any questions or need troubleshooting, please ask in the **Q&A** page.

**Integrity First:** As an open-source project, we kindly ask you to ensure the authenticity of your benchmark data when submitting it. Thank you for your support!
